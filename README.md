# RFM Customer Segmentation & E-commerce Analytics with Excel

An Excel-based e-commerce analytics project focused on **RFM customer segmentation**, sales performance, product analysis, pricing, and customer behavior.

## Dataset

The project uses an e-commerce transaction dataset containing transaction, product, customer, price, quantity, revenue, date, and country information.

**Original Dataset:** [Add Kaggle dataset link]

## Data Cleaning & Transformation

The raw dataset was cleaned and prepared for analysis by:

* Checking missing and inconsistent values
* Validating dates, numerical fields, and identifiers
* Creating calculated fields
* Creating a separate Product table
* Building relationships using Power Pivot
* Creating price categories
* Preparing customer-level data for RFM analysis

## Analysis

The Excel workbook covers:

* Sales and revenue analysis
* Product performance
* Price segmentation
* Customer purchasing behavior
* Country-level analysis
* Sales trends
* RFM customer segmentation

### RFM Analysis

Customers were scored from 1 to 10 across:

* **Recency:** How recently they purchased
* **Frequency:** How often they purchased
* **Monetary:** How much they spent

Customers were then grouped into **Champions, Loyal Customers, Potential Customers, At Risk, and Not Segmented**.

## Final Presentation

The accompanying PowerPoint summarizes the methodology, key analysis, RFM segmentation, and major business insights from the Excel workbook.
